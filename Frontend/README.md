# Ride-On Frontend

This is the frontend application for the Ride-On platform, built with modern web technologies to provide a smooth, interactive experience for users and captains.

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [GSAP](https://gsap.com/)
- **Maps & Location**: [Leaflet](https://leafletjs.com/)
- **Real-time Communication**: [Socket.io Client](https://socket.io/)
- **HTTP Client**: [Axios](https://axios-http.com/)
- **Icons**: [Remix Icon](https://remixicon.com/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository and navigate to the frontend directory:

   ```bash
   cd Frontend
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Setup Environment Variables:
   Create a `.env` file in the `Frontend` directory and add the necessary configuration variables required for Google Maps, API endpoints, etc.

4. Start the development server:
   ```bash
   npm run dev
   ```

## 🏗️ Available Scripts

- `npm run dev`: Starts the development server.
- `npm run build`: Builds the app for production.
- `npm run lint`: Runs ESLint to find linting errors.
- `npm run preview`: Locally previews the production build.
